# Фотографии

Пока настоящих снимков нет, на их местах показываются рисованные SVG-заглушки
из папки `placeholder/`. Каждая заглушка подписана именем файла, который нужно
положить вместо неё.

## Как заменить заглушку настоящим фото

1. Положите файл в эту папку (`assets/images/`) под именем из таблицы ниже.
2. Обновите страницу.

Менять HTML не нужно. У каждой картинки прописан запасной вариант: пока файла
`*.jpg` нет, показывается заглушка `placeholder/*.svg`, а как только файл
появится, страница возьмёт его.

Рекомендуемый формат: JPEG, 1600-2400 пикселей по длинной стороне.

## Права на снимки

Размещайте только те фотографии, на которые у вас есть права. Снимки с чужих
сайтов и из каталогов без разрешения автора публиковать нельзя. Архивные кадры
стоит подписывать: откуда взяты и каким годом датируются.
