# Проверки

Скрипты, которыми посчитаны и проверены числа из README и раздела 06 сайта, и их вывод в папке `logs`. Нужен только Node.js (вывод получен на версии 22). Запускать из корня репозитория.

| Команда | Что считает | Вывод |
|---|---|---|
| `node checks/site_brute.js index.html` | Берёт код расчёта прямо из `index.html` и сравнивает его с полным перебором всех исходов: 8 раундов, шум 0, 7% и 20%, все 169 пар. Затем считает кодом сайта таблицу раздела 06 и сравнивает её с `engine.js` | `logs/site_brute.log` |
| `node checks/site_vs_bench.js index.html` | Автомат Дипломата с сайта против `dip6.js` | `logs/svb.log` |
| `node checks/final_checks.js brute` | Дипломат против полного перебора при 6, 8 и 10 раундах | `logs/fc_brute.log` |
| `node checks/ref_table.js` | 50, 200 и 500 раундов | `logs/ref_table.log` |
| `node checks/check100.js` | 100 раундов | `logs/check100.log` |
| `node checks/robust.js short a3H6w1kH4K1` | 5, 10, 20 и 100 раундов при шуме 0, 2, 5, 15 и 20%. Печатает только случаи, где Дипломат не первый в турнире или в эволюции | `logs/short2.log` |
| `node checks/final_checks.js pay` | Другие выигрыши T, R, P, S | `logs/fc_pay.log` |
| `node checks/robust.js oos a3H6w1kH4K1 a4H8w1kH4K1` | Поле из 28 стратегий | `logs/oos2.log` |
| `node checks/robust.js oos a2H4w1kH4K1 a2H5w1kH4K1` | Поле из 28 стратегий для промежуточных версий | `logs/oos.log` |
| `node checks/robust.js short a2H4w1kH4K1 a2H5w1kH4K1` | Короткие матчи для промежуточных версий | `logs/short.log` |

Строка `exit 0` в конце логов — код завершения скрипта.

## Файлы

- `brute.js` — правила 12 стратегий сайта, записанные второй раз как функции от истории ходов, и полный перебор всех исходов матча.
- `dip6.js` — Дипломат с параметрами: правила (`spec`), автомат (`dip6`) и отдельная реализация по истории ходов (`twin`) для перебора.
- `engine.js` — копия точного расчёта с сайта, в которой выигрыши передаются параметром.
- `run.js` — места Дипломата в турнире и эволюции для набора условий.
- `oos.js` — 15 стратегий, которых нет на сайте; часть из них задана в `cands.js`.

## Обозначения

- Параметры Дипломата в `dip6.js` и в именах вроде `a3H6w1kH4K1`:
  - a — прибавка к подозрению за предательство без повода;
  - H — порог, с которого начинается режим вражды;
  - w — сколько взаимных предательств подряд нужно для предложения мира вне вражды;
  - kH — то же в режиме вражды;
  - K — после скольких отказов мир больше не предлагается.

  Дипломат на сайте — это a=3, H=6, w=1, kH=4, K=1; `site_vs_bench.js` сравнивает его автомат с сайтом.
- В логах `def` — 12 стратегий по умолчанию, `all` — все 13; `R200` — 200 раундов, `e0.05` — шум 5%. `tour rank` — место в турнире, `evo rank` — в эволюции, `margin` — разница с лучшей из остальных стратегий.
