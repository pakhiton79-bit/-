# Катакомбы

Шутер от первого лица в духе старого Doom. Каждый уровень - новый случайный лабиринт катакомб с тварями, аптечками и патронами. Найди светящийся портал, чтобы спуститься глубже. Чем глубже, тем больше лабиринт и злее монстры.

## Управление

На компьютере:
- `W` `A` `S` `D` - ходить, `Shift` - бежать.
- Мышь - смотреть по сторонам (после первого клика курсор захватывается), клик - выстрел.
- `←` `→` - поворот без мыши, `Пробел` - выстрел.
- `Tab` - карта, `Esc` или `P` - пауза, `M` - звук.

На телефоне:
- Левый круг - ходить.
- Правая половина экрана - веди пальцем, чтобы поворачиваться.
- Кнопка «Огонь» - держи, чтобы стрелять.

## Твари

- **Око** - летающий глаз, держит дистанцию и плюётся огнём. От плевков можно увернуться.
- **Клык** - быстрый зелёный кусака, бежит прямо на тебя.

Твари спят, пока не увидят тебя или не услышат выстрел.

## Запуск

Игра целиком в одном файле `index.html`, без сборки и зависимостей. Рекорд хранится в браузере (localStorage).
