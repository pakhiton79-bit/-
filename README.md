# Дилемма заключённого

Интерактивный симулятор из теории игр: https://pakhiton79-bit.github.io/-/

## Что внутри

1. **Правила.** Матрица выигрышей и объяснение, почему предавать выгодно, но оба в итоге проигрывают. Выигрыши T, R, P, S можно менять, всё ниже пересчитывается.
2. **Сыграйте сами.** 10 раундов против компьютера: выбранной стратегии или загадочного соперника, которого нужно разгадать. График счёта по ходу партии.
3. **Дуэль стратегий.** Две любые стратегии друг против друга: ходы по раундам, график счёта, ошибки из-за шума.
4. **Групповой турнир и эволюция.** Отмеченные стратегии играют каждая с каждой в духе турнира Роберта Аксельрода. По тем же матчам строятся два графика: средний выигрыш за раунд и то, как меняются доли стратегий в популяции, если успешные размножаются, а остальные вымирают. Настраиваются число раундов, шум (случайные ошибки) и число поколений.
5. **Выводы.** Что общего у успешных стратегий.

## Точность

Турнир и эволюция считаются точно, без случайных розыгрышей. Каждая стратегия задана конечным автоматом. Ожидаемый выигрыш M_ij стратегии i против j получается переносом распределения вероятностей по парам состояний от раунда к раунду, с учётом шума. Эволюция — дискретная репликаторная динамика x_i(t+1) = x_i(t)·f_i/f̄, где f_i = Σ_j M_ij x_j. Подробности есть на странице, в блоке «Как считается».

Для проверки правила стратегий записаны второй раз, независимо от автоматов. Для матчей из 8 раундов полным перебором всех исходов посчитаны все 144 пары стратегий при шуме 0, 7% и 20%. Расхождение с расчётом сайта не больше 2·10⁻¹², то есть только округление.

Дуэль и партия с компьютером — это одна случайная реализация матча. В дуэли рядом показано точное ожидание.

## Стратегии

Око за око, Добряк, Эгоист, Злопамятный, Око за два ока, Великодушный, Павлов, Подозрительный, Детектив, Большинство, Хитрец, Монетка.

## Запуск

Всё в одном файле `index.html`, без сборки. Графики рисует Chart.js, он подгружается с cdnjs.
