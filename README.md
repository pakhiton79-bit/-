# Храм Архистратига Михаила, посёлок Бобровский

Сайт прихода храма во имя святого Архистратига Михаила в посёлке Бобровский
Сысертского муниципального округа Свердловской области.

Статический сайт: чистый HTML, CSS и немного JavaScript. Сборка не нужна,
зависимостей нет. Оформление построено по токенам из [DESIGN.md](DESIGN.md).

## Запуск

Достаточно открыть `index.html` в браузере. Для проверки в условиях, близких
к боевым, поднимите локальный сервер:

```
python3 -m http.server 8000
```

и откройте `http://localhost:8000`.

## Страницы

| Файл | Содержание |
|------|------------|
| `index.html` | Главная: краткий рассказ, ключевые даты, разделы |
| `history.html` | История прихода от 1709 года, архитектура, источники |
| `timeline.html` | Лента времени: 16 событий с отбором по эпохам |
| `clergy.html` | Священники: настоятель и заготовки под причт прежних лет |
| `gallery.html` | Фотографии |
| `contacts.html` | Адрес, проезд, богослужения, как помочь |

## Структура

```
assets/
  css/style.css          оформление, все токены объявлены в :root
  js/site.js             подсветка якорной навигации, появление и отбор событий ленты
  images/                сюда кладут настоящие фотографии
  images/placeholder/    рисованные SVG-заглушки
  images/README.md       список файлов с описанием, что на снимке
```

## Фотографии

Настоящих снимков в репозитории нет. Пока файла `assets/images/имя.jpg` не
существует, на его месте показывается заглушка `assets/images/placeholder/имя.svg`.
Положите файл с нужным именем рядом, и страница возьмёт его сама, без правки
кода. Полный список имён и сюжетов: [assets/images/README.md](assets/images/README.md).

## Что нужно дополнить

Сайт собран по открытым источникам. Несколько мест намеренно оставлены
незаполненными, чтобы не публиковать выдуманные сведения.

- **Причт прежних лет.** Имён священников XVIII, XIX и начала XX века в
  открытых источниках найти не удалось. В `clergy.html` оставлены три
  карточки-заготовки, к каждой в коде приложен комментарий с тем, что вписать.
- **Реквизиты для пожертвований.** Не указаны сознательно: публиковать
  непроверенные банковские данные для сборов опасно. Впишите проверенные в
  раздел `#help` файла `contacts.html`.
- **Расписание богослужений.** Приводится только упоминание о молебне по
  понедельникам со ссылкой на приходской сайт.
- **Номер дома.** Справочники указывают и дом 115, и дом 116 по улице Ленина.
- **Спорные даты.** Год закрытия храма (1935, 1936 или 1938) и год начала
  восстановительных работ (2011 или 2012) в источниках расходятся. На ленте
  времени такие места помечены отдельной строкой, а не выбраны молча.
