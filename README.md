# Двойная орбита

Аркадная игра в одну кнопку. Корабль сам летит по кругу вокруг ядра, а ты перебрасываешь его между двумя орбитами, уворачиваясь от барьеров и метеоров и собирая кристаллы.

## Как играть

- Касание, клик, `Пробел`, `↑`/`↓` или `W`/`S` - сменить орбиту.
- Красные барьеры сначала мигают и пока безопасны, потом становятся смертельными.
- Пролетел впритык к метеору - бонус.
- Кристаллы подряд поднимают множитель до ×9. Если 4 секунды ничего не собрал, множитель сбрасывается.
- `P` или `Esc` - пауза, `M` - звук.

Рекорд хранится в браузере (localStorage).

## Запуск

Игра целиком в одном файле `index.html`, без сборки и зависимостей. Достаточно открыть его в браузере или опубликовать репозиторий через GitHub Pages.
