# Дилемма заключённого

Интерактивный симулятор из теории игр: https://pakhiton79-bit.github.io/-/

## Что внутри

1. **Правила.** Матрица выигрышей и объяснение, почему предавать выгодно, но оба в итоге проигрывают. Выигрыши T, R, P, S можно менять, всё ниже пересчитывается.
2. **Сыграйте сами.** 10 раундов против компьютера: выбранной стратегии или загадочного соперника, которого нужно разгадать. График счёта по ходу партии.
3. **Турнир стратегий** в духе Роберта Аксельрода. Каждая стратегия играет с каждой. Результаты показаны столбчатой диаграммой и тепловой картой «кто сколько получает против кого». Настраиваются число раундов и шум (случайные ошибки).
4. **Эволюция.** Как меняются доли стратегий в популяции, если успешные размножаются, а остальные вымирают.
5. **Выводы.** Что общего у успешных стратегий.

## Стратегии

Око за око, Добряк, Эгоист, Злопамятный, Око за два ока, Великодушный, Павлов, Подозрительный, Детектив, Монетка.

## Запуск

Всё в одном файле `index.html`, без сборки. Графики рисует Chart.js, он подгружается с cdnjs.
